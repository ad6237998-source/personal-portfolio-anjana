# Anjana Das — Personal Portfolio

A colourful, aesthetic, and responsive personal portfolio website built with **HTML, CSS, and JavaScript**. It introduces me, highlights my current skills, showcases sample projects, and provides contact links.

## ✨ Features

- Hero section with an introduction and custom illustration
- About Me section
- Skills section for C, Python, HTML, and CSS
- Project cards to showcase work
- Contact section with GitHub, LinkedIn, and email links
- Responsive layout for desktop and mobile screens
- Smooth scrolling, reveal animations, and a mobile navigation menu
- Current year displayed automatically in the footer

## 🛠️ Built With

- **HTML5** — page structure and content
- **CSS3** — colours, layout, responsive styling, and animations
- **JavaScript** — mobile menu, reveal-on-scroll effects, and automatic footer year
- **Google Fonts** — DM Sans and Playfair Display

## 📁 Project Structure

```text
Portfolio/
├── index.html
└── README.md
```

The CSS and JavaScript are currently included inside `index.html`, so no separate `style.css` or `script.js` files are required.

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also open the folder in Visual Studio Code and use the **Live Server** extension to preview the site while editing.

## 🎨 Customization

Before publishing, update these sample details in `index.html`:

- Introduction and About Me text
- Skills and project descriptions
- GitHub and LinkedIn profile URLs
- Email links (`hello@example.com`) with your preferred contact email

The project cards are examples/placeholders. Replace them with your actual projects and add links to their repositories or live demos.

## 🌐 Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` and `README.md`.
2. Open the repository on GitHub and go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and the `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.
